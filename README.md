# Be My Traveller 🏔️

Official website & client inquiry portal for **Be My Traveller** - Premium Travel & Adventure Specialist in Manali, Himachal Pradesh.

Live Custom Domain: [https://bemytraveller.com](https://bemytraveller.com)

---

## 📁 Clean Project Structure

```text
be-my-traveller/
├── index.html        # Main Launch Landing Page with Hero & Quick Inquiry
├── inquiry.html      # Dynamic Multi-step Tour Inquiry & Cost Estimator
├── styles.css        # Custom Responsive Styling & Design Tokens
├── script.js         # Interactive Logic, Live Estimator & WhatsApp Dispatch
├── CNAME             # Custom Domain routing for bemytraveller.com
├── _config.yml       # GitHub Pages site metadata
├── package.json      # Project configuration
└── README.md         # Repository documentation
```

---

## ⚡ Features

- **Dynamic Tour Planning**: Live trip cost estimates, activity selectors, and budget tier recommendations.
- **Instant WhatsApp Integration**: Pre-formatted inquiry messages dispatched directly to `+91 7018465381`.
- **Local Storage Backup**: Ensures inquiry leads are saved locally on browser submit.
- **Form Auto-Save**: Auto-saves user input every 30 seconds so visitors never lose draft details.
- **Responsive & Modern UI**: Smooth scrolling animations, glassmorphism cards, interactive floating WhatsApp button.
